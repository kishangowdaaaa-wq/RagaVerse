# RagaVerse

### Your Intelligent Carnatic Music Companion

RagaVerse is a multimodal AI-powered platform
designed for Carnatic musicians, students,
teachers, composers and music researchers.

## Core Technologies

- Python
- FastAPI
- React
- TypeScript
- OpenAI API
- LangGraph
- PostgreSQL
- Qdrant
- Librosa
- PyTorch

## Core Features

1. RagaVerse AI Assistant
2. Intelligent Raga Identification
3. AI Vocal Coach
4. AI Composition Assistant
5. Intelligent Practice Planner
6. Music Knowledge RAG System
7. Personal Music Memory
8. Multi-Agent Intelligence
